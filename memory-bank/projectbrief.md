# Project Brief

## Project Name
WMIP - What's My IP

## Core Goal
Kullanıcıların siteye girdiklerinde IP adreslerini temiz, sade ve anlaşılır bir şekilde görmelerini sağlayan web uygulaması.

## Requirements
- Siteye giren kullanıcının IP adresini göster
- Arayüz: temiz, sade, minimalist
- Sadece IP adresi odaklı (ilk aşama)
- Gelecekte genişletilebilir yapı

## Scope
İlk aşamada yalnızca IP adresi gösterimi. Sonraki aşamalarda konum, ISP, vs. eklenebilir.
